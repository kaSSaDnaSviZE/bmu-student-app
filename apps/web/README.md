# BMU Student web placeholders

Static HTML for privacy, terms, account deletion, and support. This is not an official Baku Engineering University site and it is not the Flutter client.

Before publishing, replace these tokens in the HTML files:

| Token | Meaning |
| --- | --- |
| `{{APP_NAME}}` | Product name the operator is allowed to use |
| `{{OPERATOR_NAME}}` | Legal entity that operates the service |
| `{{SUPPORT_EMAIL}}` | Real support inbox |

Do not invent phone numbers, street addresses, or a claim that the app is official BMU software. There is no npm workspace for this folder.
